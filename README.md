# 🤖 АлгоЛэнд — Алгоритмдік ойлауды үйрен!

Қазақстан мектептерінің бастауыш сынып оқушыларына арналған алгоритмдік ойлауды дамытатын интерактивті веб-платформа.

Интерактивная веб-платформа для обучения алгоритмическому мышлению учеников начальных классов казахстанских школ.

## 🎮 Ойындар / Игры

| Ойын | Сипаттама | Тақырып |
|------|-----------|---------|
| 🤖 Робот саяхатшы | Роботты бұйрықтармен басқар | Алгоритм, тізбек |
| 📊 Сұрыптау шебері | Сандарды ретке қой | Сұрыптау |
| 🧩 Заңдылық тап | Тізбектегі заңдылықты анықта | Логика, паттерн |
| 🔀 Шарт орындалды ма? | ЕГЕР-ОНДА шартын қолдан | IF-THEN |
| 🔄 Цикл суретші | Циклмен сурет сал | Цикл, қайталау |
| 📋 Блок-схема | Алгоритмді блоктардан құрастыр | Блок-схема |

## 🚀 Іске қосу / Запуск

Серверсіз жұмыс істейді — `index.html` файлын браузерде ашсаңыз жеткілікті.

Работает без сервера — просто откройте `index.html` в браузере.

### GitHub Pages

1. Репозиторийді GitHub-қа жүктеңіз
2. **Settings → Pages → Source** → `main` branch, `/ (root)` таңдаңыз
3. Сайт `https://username.github.io/algoland/` мекенжайында қолжетімді болады

## 🛠 Технологиялар

- HTML5 + CSS3 + Vanilla JavaScript
- Сыртқы тәуелділіктер жоқ (тек Google Fonts)
- localStorage арқылы прогресс сақталады
- Адаптивті дизайн (мобильді құрылғыларға бейімделген)
